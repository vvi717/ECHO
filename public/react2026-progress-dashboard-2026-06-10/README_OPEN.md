# REACT2026 Submission Readiness Dashboard - Open Guide

Open `index.html` in a browser.

Recommended use:

1. Use the left navigation as slide sections.
2. Start from Overview and Submission Gate for the latest June 22 status.
3. Use the evidence explorer buttons to review the earlier Big-Five local-validation evidence.
4. Use keyboard arrows to move between sections.
5. Use `Print / PDF` if a static handout is needed.

Speaker prep / backup files:

- `CHINESE_PRESENTATION_WALKTHROUGH_2026-06-10.md`: earlier Chinese speaking guide for the June 10 evidence discussion.
- `SEED_LEVEL_BACKUP_TABLE_2026-06-10.md`: historical seed-level backup table for Big-Five V1 supervisor questions.
- `SEED_LEVEL_BACKUP_TABLE_2026-06-10.csv`: machine-readable version of the historical seed-level backup table.

Important caveat:

This dashboard summarizes local validation, test-inference, and submission-readiness evidence. It is not an official challenge result or final official submission.
